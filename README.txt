PROJECT EKEMINI — BIRTHDAY WEBSITE
===================================

Included:
- index.html, style.css, script.js
- Seven local MP4 memory videos in assets/videos/
- Three still-image memory cards in assets/images/
- Six interactive romantic letters
- Flirty birthday surprise
- Birthday celebration interaction and confetti
- Davido song links (YouTube opens the songs; no copyrighted music files are bundled)

RUN LOCALLY:
1. Extract this ZIP.
2. Open the extracted Project_Ekemini_Professional folder in VS Code.
3. Open index.html and click Go Live (Live Server extension), or open index.html in a browser.
4. Keep assets/ beside index.html. Do not move the videos out of assets/videos.

HOST ONLINE WITH NETLIFY:
1. Extract the ZIP on your computer.
2. Open the folder named Project_Ekemini_Professional.
3. Visit https://app.netlify.com/drop and sign in/create a Netlify account.
4. Drag the entire Project_Ekemini_Professional folder onto the Drop area.
5. Wait for the deploy to finish, then open the generated website URL and test all seven videos.
6. Save the URL and share it with Ekemini.

IMPORTANT:
- The four newly added videos are named ekemini-04.mp4 through ekemini-07.mp4.
- The website includes the three original videos plus these four new uploads.
- Music links open YouTube because the site does not include licensed Davido audio files.
- If Netlify's interface asks for a folder, drag the extracted folder itself, not just index.html.
- Test the deployed link on your phone before sending it.
